---------------------------------------------------------------
 R Export (convert_combined_to_scenic.R)
Takes the combined Seurat object and exports:

rna_matrix.mtx, rna_features.tsv, rna_barcodes.tsv, rna_cell_metadata.csv
atac_matrix.mtx, atac_barcodes.tsv, peaks.bed, atac_cell_metadata.csv
fragments_paths.json, umap_combined.csv

Known issue introduced here: peaks.bed gets chr prefix forced onto chromosomes, while the Ensembl genome FASTA uses bare numbers. This mismatch propagates through the entire pipeline and required multiple downstream patches.

2. Genome Annotation (make_genome_annots.py)

Queries Ensembl BioMart for ggallus_gene_ensembl to produce genome_annotation.tsv (Chromosome, Start, End, Strand, Gene, ensembl_gene_id, TSS, Transcript_type)
Extracts chromosome sizes from Gallus_gallus.GRCg6a.dna.toplevel.fa to produce chromsizes.tsv
Chromosome names are bare numbers (consistent with Ensembl format) — correctly no chr prefix here


3. cisTopic ATAC Processing
Using pycisTopic on the exported ATAC matrix + peaks.bed:

Built a cisTopic object, ran LDA topic modeling
Selected the best model
Saved as atac_cistopic_selected_model_chrstr.pkl
Region names in the object have format :1:33501-34428 (colon-prefixed bare numbers — the chr from peaks.bed was stripped somewhere during cisTopic processing)
Ran binarize_topics (Otsu method) → region_sets_topics_otsu.pkl (12 topics)


4. RNA Processing
Using scanpy on the exported RNA matrix:

Normalized, log-transformed, selected 3,000 HVGs
Computed UMAP, assigned cell types (15 cell types)
Saved as rna_scanpy_preprocessed.h5ad
Gene IDs are gene symbols (not Ensembl IDs) — confirmed 2,959/3,000 overlap with genome annotation


5. Consensus Peaks + cisTarget DB Build
On OSC (separate HPC job via run_cistarget_db_osc.sh):
First, built consensus_regions.fa:

Started from cisTopic region names (:1:33501-... format)

117,521 sequences — more regions than cisTopic's 50,187 (the consensus was broader, likely from all samples merged before cisTopic filtering)
